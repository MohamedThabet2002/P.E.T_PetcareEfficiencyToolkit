===============================================================================
                PETCARE EFFICIENCY TOOLKIT (P.E.T) - USER GUIDE
===============================================================================
Version: 1.0.0
Developed by: Mohamed Thabet

Thank you for using the Petcare Efficiency Toolkit. This application is designed 
to provide a complete solution for managing veterinary clinical records, 
inventory, and finances.

-------------------------------------------------------------------------------
1. REQUIREMENTS:
-------------------------------------------------------------------------------
Windows 7 or up

-------------------------------------------------------------------------------
2. WARNING:
-------------------------------------------------------------------------------
If you decide to uninstall the application, your data is NOT automatically 
deleted. However, if you manually delete the folder located at:
{%LocalAppData%\Petcare Efficiency Toolkit (P.E.T)}

You will lose all patient records, inventory history, and financial data.
!!! DELETING THE FILE IS IRREVERSIBLE !!!

-------------------------------------------------------------------------------
3. KEY FEATURES
-------------------------------------------------------------------------------
* PATIENT MANAGEMENT: Track owners, pets, and full medical visit histories.
* INVENTORY TRACKING: Manage clinical supplies with automated stock alerts.
* FINANCIAL TOOLS: Generate sales receipts and track clinic expenses.
* ANALYTICS: View real-time charts for revenue and visit trends.
* MULTI-LANGUAGE: Full support for English and Arabic (RTL) interfaces.
* DARK MODE: Switch between light and dark themes via the top status bar.
* DATA SECURITY: Automatic database backups are created on application exit.

-------------------------------------------------------------------------------
4. DATA & BACKUPS
-------------------------------------------------------------------------------
Your data is stored locally on your machine for maximum privacy.

Location: %LocalAppData%\Petcare Efficiency Toolkit (P.E.T)

The system automatically maintains a 7-day backup rotation. You can manage 
these files or create manual backups through the "Settings" menu inside 
the application.
